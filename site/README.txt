Сюда кладём игры и программы для окна MS-DOS: файлы .jsdos
(zip с файлами игры и .jsdos/dosbox.conf внутри).
Собрать .jsdos из обычного zip можно прямо на сайте: окно MS-DOS -> список -> «Студия .jsdos»
(или на https://dos.zone/studio).
После этого добавить строку в DOS_GAMES в script.js.

ВАЖНО: если заменили файл игры на сервере — поменяйте адрес в DOS_GAMES (assets/games/doom.jsdos?v=2),
иначе у посетителей, уже открывавших игру, останется старая версия из кэша браузера.
Сохранения при смене ?v не теряются.
