# Как добавить новую «программу» на сайт

Сайт — это рабочий стол Windows 95. Каждый блок информации — «программа»: **ярлык** на рабочем столе
и **окно**, которое этот ярлык открывает. Всё лежит в одном файле `site/index.html`.

Чтобы быстро найти нужное место, ищите в файле подписи-комментарии (`ОКНО Minecraft`, `4. ЯРЛЫКИ`, `7. PONG` и т. д.).

## Из чего состоит файл

| Часть | Что внутри |
|---|---|
| Блок `style` | Весь внешний вид. Разделы: база, обои и ярлыки, окна, панель задач, телефон |
| Разметка `body` | Холст обоев, иконки-«спрайты», ярлыки, окна, меню «Пуск», панель задач |
| Блок `script`, разделы 1–8 | Утилиты, тексты RU/EN, окна, ярлыки, события, лавовая лампа, Pong, главный цикл |

## Новая программа за 3 шага

Пример: программа «Привет» (окно с текстом). Везде используется один и тот же **id** — `hello`.

### Шаг 1. Ярлык

Вставьте в блок `РАБОЧИЙ СТОЛ` (внутрь `<nav id="icons">`). Порядок ярлыков = порядок в HTML.

```html
<button class="icon" data-open="hello">
	<span class="ic">👋</span>
	<span data-t="iHello">Привет</span>
</button>
```

- `data-open="hello"` — id окна, которое откроет ярлык.
- `data-t="iHello"` — ключ перевода подписи (см. шаг 3).
- Пункт в меню «Пуск» и кнопка на панели задач появятся сами, ничего добавлять не нужно.

### Шаг 2. Окно

Вставьте рядом с другими окнами (например, перед окном `err`).

```html
<section class="win raised" id="hello" data-icon>
	<header class="tb">
		<span class="ti"></span>
		<span class="tt" data-t="tHello">Привет.exe</span>
		<span class="tbb">
			<button data-act="min">_</button>
			<button data-act="max">□</button>
			<button data-act="close">×</button>
		</span>
	</header>
	<div class="body">
		<p data-t="helloTxt">Привет! Это моя новая программа.</p>
	</div>
</section>
```

- `id="hello"` должен **совпадать** с `data-open` у ярлыка и быть уникальным (`err` занят предупреждением).
- `data-icon` — из-за него в заголовок окна копируется иконка ярлыка.
- Внутри `.body` можно класть что угодно: текст, картинки, кнопки, поля (примеры ниже).
- Перетаскивание, сворачивание, разворачивание, закрытие и случайное место при открытии работают автоматически.

### Шаг 3. Тексты на двух языках

В скрипте, раздел `2. ТЕКСТЫ (RU / EN)`, добавьте ключи **в оба языка** (`ru` и `en`):

```js
// в ru: { ... }
iHello: 'Привет',
tHello: 'Привет.exe',
helloTxt: 'Привет! Это моя новая программа.',

// в en: { ... }
iHello: 'Hello',
tHello: 'Hello.exe',
helloTxt: 'Hello! This is my new program.',
```

Если ключа нет в одном из языков, на месте текста появится `undefined`.
Текст без `data-t` не переводится — он будет одинаковым на обоих языках (так сделаны названия «Minecraft» и «Discord»).

Готово: сохраните файл и обновите страницу.

## Рецепты

### Иконка ярлыка: три способа

```html
<!-- 1. Эмодзи -->
<span class="ic">🎲</span>

<!-- 2. Картинка: положите файл в site/assets/ -->
<span class="ic"><img src="assets/my-icon.png" alt=""></span>

<!-- 3. Своя SVG: опишите один раз в блоке «ИКОНКИ-спрайты»... -->
<symbol id="i-my" viewBox="0 0 32 32"><rect x="4" y="4" width="24" height="24" fill="#fff" stroke="#000"/></symbol>
<!-- ...и подключите в ярлыке -->
<span class="ic"><svg><use href="#i-my"></use></svg></span>
```

### Кнопка-ссылка и кнопка «Копировать» внутри окна

```html
<a class="btn" href="https://example.com" target="_blank" rel="noopener noreferrer" data-t="openSite">Открыть сайт</a>

<div class="row">
	<input readonly value="текст для копирования">
	<button class="btn" data-copy="текст для копирования" data-t="copy">Копировать</button>
</div>
```

Ключ `copy` уже есть в словаре, второй раз его добавлять не нужно.

### Размер окна

В блоке стилей, раздел «Окна», рядом с `#pong { ... }`:

```css
#hello {
	width: 480px;
}
```

На телефоне ширину окна задаёт сайт сам, этот размер там игнорируется.

### Открывать окно сразу при заходе

В конце скрипта (раздел `8. ГЛАВНЫЙ ЦИКЛ И ЗАПУСК`) найдите список `['about', 'mc', 'dc', 'tg', 'mail']` и добавьте свой id.
Окна из списка открываются на компьютере в случайных местах. На телефоне сразу показывается только предупреждение.

### Программа с собственной логикой (игра, анимация)

Так устроен Pong (раздел `7. PONG`). Скелет:

```js
// рядом с разделом 7: окно и функция «шаг»
const hw = $('#hello');
function helloStep(dt) {                      // dt — секунд с прошлого кадра
	if (!hw.classList.contains('open') || hw.classList.contains('min')) {
		return;                                // окно закрыто или свёрнуто — ничего не делаем
	}
	const active = cur === hw;                 // окно сейчас активно? (иначе лучше поставить паузу)
	// ...обновить состояние и нарисовать
}

// в разделе 8, в функции tick(ts), рядом с pongStep(dt):
helloStep(dt);
```

Внутри окна можно разместить `<canvas>` (как `#pc` у Pong). Управление с клавиатуры принимайте только когда `cur === hw`,
иначе стрелки будут двигать игру, пока вы работаете в другом окне.

## Где менять данные проекта

| Что | Где |
|---|---|
| Текст «Обо мне» | Ключ `aboutTxt` в словаре (раздел 2), оба языка |
| Ссылка на Discord | В окнах `mc` и `dc`: поле `value` и `href` (поиск по `discord.gg`) |
| Telegram-канал | В окне `tg`: поле `value` и `href` (поиск по `t.me`) |
| Почта | В окне `mail`: `value` и `data-copy` |
| Адрес Minecraft-сервера и порт | В окне `mc`: `value` и `data-copy` в двух строках |
| Предупреждение «в разработке» | Ключ `wip` (текст), окно `err` (удалите окно и строку `open('err')`, чтобы убрать совсем) |

## Настройка лавовой лампы

Раздел `6. ОБОИ` в скрипте:

| Что поменять | Где |
|---|---|
| Количество дыр | В `lavaInit`: константа `n` (минимум 10, максимум 26) |
| Размер дыр | В `lavaInit`: `r: u * (.035 + R * R * .15)`. Увеличьте `.15`, чтобы появились крупные |
| Скорость | В `lavaInit`: `fx` (по горизонтали) и `fy` (по вертикали), чем больше число, тем быстрее |
| Цвет сыра | В `lava`: `cr`, `cg`, `cb` (красный, зелёный, синий) |
| Цвет дыр | В `lava`: числа `168`, `104`, `18` (край дыры) и `62`, `48`, `8` (насколько темнее в центре) |

Если у посетителя включено «уменьшить движение» в системе, лампа остаётся неподвижной картинкой.

## Как посмотреть результат и выложить

1. **Локально:** откройте папку `site` в VS Code, установите расширение **Live Server**, правой кнопкой по `index.html` → *Open with Live Server*.
2. **На сайт:** закоммитьте изменения и отправьте в ветку `main`. GitHub Actions (`.github/workflows/deploy.yml`) сам скопирует папку `site/` на сервер.

## Если что-то не работает

- **Ярлык не открывает окно:** `data-open` у ярлыка и `id` у окна написаны по-разному.
- **В заголовке окна нет иконки:** забыли атрибут `data-icon` у `<section>`.
- **Вместо текста `undefined`:** ключ из `data-t` не добавлен в один из языков в словаре.
- **Страница стала пустой:** скорее всего, ошибка в скрипте. Откройте консоль браузера (`F12`) и посмотрите красную строку.
- **Ничего не меняется после правки:** обновите страницу без кеша (`Ctrl+F5`).
