Hello! Vladimir "Cheese" Maasdam here. Today I'd like to tell you about our game servers and how you can join them.

We will soon be launching two multiplayer game servers.

## RimWorld

The first one is a server for *RimWorld* version 1.6.

To play, you will need:
- RimWorld 1.6 (legal or unofficial copies are both supported)
- The Ideology, Royalty, Biotech, Anomaly, and Odyssey DLCs
- The Online City 1.6 mod:
https://steamcommunity.com/sharedfiles/filedetails/?id=3572429738

The unique feature of this mod is that all players share the same planet. You can trade with other colonies, form alliances, and interact with other players. Saves are stored on the server, and everyone plays under the same storyteller: Randy Random.

![LoginScreen](/src/assets/mod_log_rim.jpg)

![TradeScreen](/src/assets/mod_show_rim.jpg)

To connect, use:

**maasdam.online:30010**

If the game freezes while connecting, that's normal. Using a VPN may cause significant synchronization delays. The server is located in Moscow, so players connecting from Russia should experience good connection quality.

## Minecraft

I am currently preparing a Minecraft server based on the Sanctuary world-generation mod:

https://www.reddit.com/r/Minecraft/comments/1spy655/sanctuary_a_minecraft_worldgen_mod_where_you/

This mod for Minecraft 1.21.11 completely changes world generation by replacing the normal terrain with floating islands.

To join the server, you must first join our Discord server and be added to the whitelist.

At launch, the server will support up to 50 players. If performance remains stable, the player limit will be increased.

![Spawn](/src/assets/spawn_mine.jpg)

![Horizon](/src/assets/horizon_mine.jpg)

You will be able to connect using:

**mc.maasdam.online**

or

**maasdam.online:30002**

You may also install the Simple Voice Chat mod if you would like to use proximity voice chat.
